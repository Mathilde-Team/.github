# Mathilde-Team

Logiciels libres : outils réseau et d'administration (Gcm4, Netcross, SwitchCapture, AsyncRdp4, AsyncVnc4, RsysLogstach…) et domotique (compteur d'eau wM-Bus ESPHome).

Toutes les productions suivent le même [socle qualité](https://github.com/Mathilde-Team/.github/blob/main/SOCLE.md) :
- licence **MIT** ;
- branches `main` (livraison) et `dev` (intégration) protégées ;
- CI obligatoire ;
- garde `dev` → `main`.

Pour démarrer un nouveau projet, utilise le modèle [modele-depot](https://github.com/Mathilde-Team/modele-depot).
